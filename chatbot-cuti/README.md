# 🤖 Chatbot Cuti & Izin Sakit

Aplikasi chatbot untuk mengajukan cuti dan izin sakit karyawan.

## Fitur
- 📅 Pengajuan Cuti (Tahunan/Mendesak/Besar)
- 🏥 Pengajuan Izin Sakit
- 📊 Riwayat Pengajuan
- 💬 Interface Conversational

## Cara Menjalankan
```bash
pip install -r requirements.txt
streamlit run st.py
```
